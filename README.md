To-Do List Website

About the Project

A simple and user-friendly To-Do List web application that helps users organize their daily tasks and manage their work efficiently.

Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- View and manage the task list
- Simple and user-friendly interface
- Responsive design for different screen sizes

Technologies Used

- HTML
- CSS
- JavaScript

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.


Purpose

This project was created to practice front-end web development using HTML, CSS, and JavaScript.
